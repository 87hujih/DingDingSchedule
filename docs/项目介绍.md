# Schedule Server - 多租户排课考勤管理系统

## 1. 项目简介

Schedule Server 是一套面向教育/培训机构的**多租户排课考勤管理系统**，深度集成钉钉开放平台。主要功能包括：

- 课程表导入与管理
- 按周/日考勤统计
- 请假审批同步与考勤扣减
- 学期与作息时间配置

系统采用 **B/S 架构**，后端基于 Go（Gin 框架）开发。前端可对接钉钉小程序、钉钉 H5 或独立 Web 应用。

## 2. 核心功能需求

### 2.1 用户与组织管理

| 需求 | 说明 |
|------|------|
| 钉钉单点登录 | 用户通过钉钉免登码登录，服务端换取钉钉身份后签发 JWT |
| 用户同步 | 批量从钉钉同步用户信息（含拼音索引），保持本地数据一致 |
| 部门同步 | 从钉钉拉取组织架构，存储为本地部门记录 |
| 角色权限 | 0=普通用户（仅可访问自己数据），1=管理员（租户级），2=超级管理员（预留） |
| 考勤参与 | 用户和部门可切换是否参与考勤 |

### 2.2 课程排班

| 需求 | 说明 |
|------|------|
| 文件导入 | 通过 Excel（.xls/.xlsx）导入用户课表，全量覆盖 |
| 周次列表 | 周次以字符串存储（如 "1,2,3,5,8-10"），支持连续/离散周 |
| 学期关联 | 导入时自动关联当前激活学期，支持多学期归档 |
| 手动编辑 | 对单个课程进行增删改查 |

### 2.3 考勤统计

| 需求 | 说明 |
|------|------|
| 实时计算 | 根据日期、周次、节次计算「应到 = 候选人 - 有课人员」 |
| 请假扣减 | 当请假审批通过且与节次时间窗口重叠时，计入请假列表 |
| 快照存储 | 管理员可手动触发统计并持久化，用于历史查询 |
| 部门筛选 | 支持按部门 ID 列表过滤考勤范围 |

### 2.4 请假审批同步

| 需求 | 说明 |
|------|------|
| 回调接收 | 接收钉钉审批流程事件回调，存入 `leave_approvals` 表 |
| 幂等处理 | 使用 `(tenant_id, process_instance_id)` 唯一约束保证幂等 |
| 时间窗口匹配 | 使用半开区间 [start, end) 与节次时间做重叠检测 |

### 2.5 学期与作息配置

| 需求 | 说明 |
|------|------|
| 学期管理 | 配置学期名称、起始日期、总周数；每租户仅一个激活学期 |
| 作息模式 | 支持上学/假期模式；考勤按当前激活模式计算 |
| 作息时段 | 每种模式下可配置多个时间段（起止时间、排序） |

```
+--------------------------------+---------------------------------+
                                 | HTTP/HTTPS
+--------------------------------v---------------------------------+
|                          Gin Router                              |
|  +---------------+  +---------------+  +----------------------+  |
|  | JWT 认证中间件 |  | 管理员权限校验 |  | 租户隔离中间件        |  |
|  +---------------+  +---------------+  +----------------------+  |
+--------------------------------+---------------------------------+
                                 |
+--------------------------------v---------------------------------+
|                           Handler 层                             |
|  auth_handler / user_handler / schedule_handler / attendance_..  |
+--------------------------------+---------------------------------+
                                 |
+--------------------------------v---------------------------------+
|                           Service 层                             |
|  业务逻辑：考勤计算、请假扣减、课表导入、钉钉同步 ...             |
+--------------------------------+---------------------------------+
                                 |
+--------------------------------v---------------------------------+
|                          Repository 层                           |
|  GORM 数据访问 + 自动租户隔离插件                                 |
+--------------------------------+---------------------------------+
                                 |
+--------------------------------v---------------------------------+
|                           MySQL                                  |
+------------------------------------------------------------------+
```

## 6. 数据模型概览

### 6.1 核心数据表

| 表名 | 说明 |
|------|------|
| `tenants` | 企业租户（corp_id、钉钉凭证） |
| `users` | 用户（钉钉 ID、拼音索引、角色、考勤状态） |
| `departments` | 部门（钉钉 dept_id、父部门、叶子标记） |
| `user_departments` | 用户-部门关联（多对多） |
| `courses` | 课程（user_id、semester_id、周次列表、节次） |
| `semesters` | 学期（起始日期、总周数、激活标记） |
| `attendance_records` | 考勤快照（日期+节次唯一、JSON 存储用户 ID） |
| `leave_approvals` | 请假审批（钉钉流程实例 ID、时间范围、状态） |
| `schedule_settings` | 作息设置（当前模式） |
| `schedule_periods` | 作息时段（模式 + 节次 + 时间窗口） |

### 6.2 租户隔离

所有带 `tenant_id` 字段的表均由 GORM 插件自动过滤，无需手动编写 WHERE 条件。

## 7. API 模块

| 模块 | 路由前缀 | 说明 |
|------|----------|------|
| 认证 | `/api/auth` | 登录（钉钉 SSO） |
| 用户 | `/api/users` | 个人信息、搜索 |
| 管理 | `/api/admin` | 用户/部门同步、状态管理 |
| 课表 | `/api/schedules` | 导入、按周查询、增删改查 |
| 考勤 | `/api/attendance` | 时段状态、请假明细、统计记录 |
| 学期 | `/api/semesters` | 当前激活学期 |
| 作息设置 | `/api/schedule` | 作息信息、模式切换 |

详细接口规范请参阅 `FRONTEND_API_SPEC.md`。

## 8. 运行与部署

### 8.1 本地开发

```bash
# 1. 准备数据库（MySQL 8.0+）
# 2. 复制 configs/config.yaml.example -> configs/config.yaml 并填写配置
# 3. 运行
go run cmd/main.go
```

### 8.2 生产部署

- 使用 `config_prod.yaml` 作为生产环境配置
- 推荐：Docker / Kubernetes 部署
- 日志输出至 `logs/app.log`，支持自动轮转

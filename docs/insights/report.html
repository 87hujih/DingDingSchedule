问题出现的地方

您遇到的摩擦来自 Claude 采取错误的方法、对已经正确的代码进行冗余更改，以及在更简单的操作就足够时过于彻底。

对已经正确的代码进行冗余工作
Claude 修改了先前提交中已经处于所需状态的代码，浪费了不必要更改的时间。您应该在请求修改之前更仔细地验证当前状态，或者要求 Claude 首先确认需要更改什么。
  • Claude 将代码转换为使用弱 RPC 依赖，而它已经从早期提交中弱依赖，执行了冗余修改
  • Claude 尝试重启已经成功运行的服务，导致不必要的端口冲突错误
错误的初始方法
Claude 采取了需要纠正和解释的错误方法，减慢了您的进度。您可以预先提供更多关于系统架构的上下文，或者在实施之前要求 Claude 解释推荐的方法。
  • 您尝试通过 URL 参数传递 WebSocket 连接的身份验证令牌，但 Claude 必须解释正确的基于消息的身份验证流程
  • Claude 的初始调试策略没有考虑实际的 API 响应结构，需要额外的调查来识别真正的问题
过度彻底导致中断
Claude 有时会在您已经获得所需内容时继续执行额外步骤，导致您中断工作流程。您可以更明确地表示希望进行最小更改，或者要求 Claude 在继续下一步之前确认。
  • 您在从 Git 跟踪中删除文件时中断了最后的暂存步骤，表明 Claude 对完整工作流程过于彻底
  • Claude 可能在多个步骤中移动得太快，而没有在操作之间暂停以获得您的确认

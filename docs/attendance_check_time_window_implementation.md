# 考勤打卡时间窗口修改 - 实施记录

## 修改完成时间
2026-01-31

## 修改文件
- `internal/service/attendance_record_service.go`

## 修改内容

### 1. 新增方法：calculateCheckWindowStart

**位置**：第181-216行

**功能**：计算打卡窗口开始时间
- 第1节：从当天 00:00:00 开始
- 第2节及以后：从上一节的下课时间开始

**代码**：
```go
func (s *AttendanceRecordService) calculateCheckWindowStart(
    ctx context.Context,
    date time.Time,
    section int,
) (time.Time, error)
```

### 2. 修改方法：getOnTimeUsers

**位置**：第275-409行

**主要变更**：

#### a. 方法签名变更
- **新增参数**：`section int` - 节次（用于计算打卡窗口）
- **注释更新**：从"在截止时间前打卡的人"改为"在有效时间窗口内打卡的人"

#### b. 查询逻辑变更
```go
// 旧逻辑
queryStart := time.Date(date.Year(), date.Month(), date.Day(), 0, 0, 0, 0, date.Location())

// 新逻辑
windowStart, err := s.calculateCheckWindowStart(ctx, date, section)
queryStart := windowStart
```

#### c. 打卡有效性判断变更
- **新增检查**：打卡时间必须 >= 窗口开始时间
- **新增统计**：`tooEarlyCount` - 早于窗口的打卡数
- **新增日志**：记录"打卡时间早于有效窗口"的情况

#### d. 日志输出增强
- 增加"窗口开始"时间显示
- 增加"早于窗口"统计
- 修改"未打卡"计算公式：`len(users)-len(onTime)-lateCount`

### 3. 修改方法：GetAttendanceDetail

**位置**：第96-101行

**变更**：调用 `getOnTimeUsers` 时传入 `req.Section` 参数

```go
// 旧调用
onTime, err := s.getOnTimeUsers(ctx, shouldAttend, date, slotStart, slotEnd)

// 新调用
onTime, err := s.getOnTimeUsers(ctx, shouldAttend, date, req.Section, slotStart, slotEnd)
```

## 业务逻辑变更

### 变更前
- 查询范围：当天 00:00:00 到下课时间
- 判断标准：打卡时间 ≤ 上课时间 → 正常打卡
- 效果：一次打卡全天有效

### 变更后
- 查询范围：窗口开始时间到下课时间
- 判断标准：
  1. 打卡时间 >= 窗口开始时间（新增）
  2. 打卡时间 ≤ 上课时间
- 效果：每节课需要单独打卡

```
用户在 07:50 打卡
窗口：00:00 - 08:00

#### 场景2：查询第2节（早上打卡）
```
用户在 08:00 打卡

```

#### 场景3：查询第2节（中午打卡）
```
用户在 13:00 打卡
窗口：11:50 - 14:00
结果：13:00 在窗口内 且 13:00 < 14:00 → 正常打卡 ✅
```

#### 场景4：查询第2节（迟到）
```
用户在 14:10 打卡
窗口：11:50 - 14:00

## 注意事项

### 1. 配置依赖
当前实现使用配置文件 `s.scheduleCfg.Periods` 作为回退方案。
实际运行时，系统会从数据库的 `schedule_periods` 表读取配置。

### 2. 模式切换
系统支持两种模式：
- **假期模式（holiday）**：3个时段
- **上课模式（school）**：5个时段

切换模式后，系统会在5分钟内自动重载配置。

### 3. 历史数据
已保存的考勤记录不会自动更新。
如需重新统计，可使用手动触发接口：
```bash
POST /api/admin/attendance/record/trigger
```

### 4. 边界情况
- 第1节的窗口从 00:00 开始，可能太早
- 跨天的情况（如果有晚上的课延续到第二天）
- 节假日的处理
